# RevVue — Project Workflow

## 1. Project Setup

- Clone the GitHub repository.
- Open notebooks using Google Colab.
- Mount Google Drive to access the shared dataset.
- Install dependencies from requirements.txt.

## 2. Project Structure

- Checkpoint-02.ipynb — Data preprocessing and analysis
- data/ — Shared dataset stored in Google Drive
- requirements.txt — Python dependencies
- contributions.md — Individual contribution tracker

## 3. Development Workflow

1. Pull the latest changes from GitHub.
2. Make changes to your assigned portion.
3. Test your code and save your notebook.
4. Commit changes with a descriptive message.
5. Push changes to GitHub.

## 4. Git Commands

    git pull --ff-only origin main
    git status
    git add <filename>
    git commit -m "Describe changes"
    git push origin main

## 5. Team Collaboration

- Use individual Git working copies when possible.
- Avoid simultaneous Git operations in the shared Drive folder.
- Keep the original dataset unchanged.
- Do not upload datasets or credentials to GitHub.
- Update contributions.md after completing assigned tasks.
- Resolve merge conflicts before pushing changes.
