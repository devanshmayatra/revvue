# RevVue

Consumer sentiment and brand perception analysis using public reviews.

## About

RevVue is a data science coursework project that aims to explore public reviews to understand customer opinions and how consumers perceive different brands.

## Goals

- Clean and explore review data.
- Analyze positive, negative, and neutral sentiment.
- Identify common themes in customer feedback.
- Compare sentiment across brands and visualize the findings.
